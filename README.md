**The Student Performance Analyzer** is a **Python-based application** designed to help students analyze their **academic performance** and understand their overall results. 
The operating principle is simple and the program is meticulously designed to benefit its users. They can easily enter their grades and the program provides several useful features:
     
     - Calculates their average grade
     - Identifies the strongest and weakest subjects 
     - Calculates the score required for a specific desired result 
     - Supports customizable grading ranges
     - Validates user input 
     - Compiles basic performance statistics 
     - Saves the results to a text file.
     - Generates a brief academic performance report 
The project was developed as part of my **independent study** of the Python programming language and aims to demonstrate how programming can be used to solve practical problems in real-world scenarios.

# How the Analyzer Works?
1. The user enters their **name** and defines the **grading range**.
2. The user enters their **subjects** and **grades**.
3. The application **analyzes** the entered results. 
4. The program **calculates the average, highest and lowest grades, and strongest and weakest subjects.**
5. The user can enter a **desired average** and calculate the ****grade required** to achieve it**.
6. The application generates an **overall performance assessment**. 
7. The results are saved in an **academic performance report**.

# How to run
